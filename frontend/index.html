SDC-V Structural Design Copilot

The AI drafts; the code checks; the engineer signs.

IS 456:2000

Draft reinforced-concrete beam designs to IS 456:2000, with every number checked.

Describe a beam in plain English or fill in a form. A deterministic calculator produces the numbers, clause-tagged rules decide pass or fail, and the language model only reads your brief and explains the result.

Example run

A 250 x 400 mm beam is too shallow. Watch the pipeline find a section that passes.

    What it can do

    • Design singly reinforced rectangular beams (simply supported or cantilever, UDL): flexure, shear, deflection, bar and stirrup detailing.
    • Understand a written brief or a photo of a problem, and ask for missing values instead of guessing.
    • Verify with 19 clause-tagged rules, then enlarge the section automatically if a check fails.
    • Explore nearby sections and find the lightest one that passes.
    • Explain in a narrative where every number is traced back to the verified result.
    • Record every run in an audit log, with CSV and Markdown export.
    • Look up structural engineering reference material in the knowledge base.
    • Inspect the facts, rules and meta-rules behind the calculator in the expert system view.
